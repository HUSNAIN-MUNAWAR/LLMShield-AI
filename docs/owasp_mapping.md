# OWASP-style Mapping

This project uses OWASP Top 10 for LLM Applications inspired labels such as LLM01 Prompt Injection, LLM02 Sensitive Information Disclosure, LLM04 Data and Model Poisoning, LLM06 Excessive Agency, LLM07 System Prompt Leakage, LLM09 Misinformation, and LLM10 Unbounded Consumption.
