# Security Policy

## Supported version

Security fixes are applied to the latest revision on the default branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use the repository's [private vulnerability reporting form](https://github.com/HUSNAIN-MUNAWAR/LLMShield-AI/security/advisories/new) and include:

- the affected component and version or commit;
- clear reproduction steps;
- the observed and expected behavior;
- the potential impact; and
- any suggested mitigation.

Reports will be acknowledged as soon as practical. A remediation timeline will be shared after the issue is reproduced and assessed.

## Scope and safe use

LLMShield AI is intended for authorized defensive testing of local demos, user-owned systems, and explicitly permitted endpoints. Do not use it against third-party systems without authorization.
